# WP-007 — Garden-governed evolution pipeline

Status: REFERENCE IMPLEMENTATION COMPLETE — PENDING INTEGRATION

## Objective

Treat the pipeline that reviews, implements, and evolves Garden as a Garden application rather than as adjacent automation. Existing Garden/GSL mechanisms govern the pipeline: typed ACTION semantics, DesignEpoch, bounded authority, ActionGate, immutable predecessor releases, and human canonical-promotion authority.

## Existing canonical obligation basis

This work package is a DERIVATION from existing v15.5 mechanisms, not a new top-level architecture proposal.

- `canonical/current/Garden_System_v15.5_FULL_2026-09-12.txt` already specifies an agent proposal path through capability lookup, principal/delegation checks, deterministic ActionGate, safety/assurance gates where applicable, dispatch, and effect receipt/reconciliation.
- The same canonical System source already requires governed DesignEpoch transitions for authoritative semantic change and binds candidate generation/materialization to source hashes and DesignEpoch.
- Published v15.5 remains immutable. Successor materialization is governed separately by WP-006 and does not itself imply canonical promotion.

## Implemented correctness sequence

1. **Typed verbs** — `PROPOSE`, `TRIAGE`, `TEST`, `ACCUMULATE`, `MATERIALIZE` have explicit pre/post conditions in `evolution_actions.py`. Materialization is candidate-only and cannot move the canonical pointer.
2. **Epoch-bound evolution artifacts** — `FINDING`, `TEST`, and `DELTA` bindings are `CURRENT`, `STALE`, or `UNKNOWN`; only `CURRENT` artifacts may accumulate. Re-derivation creates a new provenance-linked artifact rather than rewriting an old binding.
3. **Bounded agent authority** — reviewer/test-writer/integrator/accumulator/materializer roles have narrow verb authority. Agents cannot self-mint envelopes, cannot hold canonical-promotion authority, and delegation cannot expand actions/resources/depth.
4. **Evolution ActionGate** — typed action, authority, epoch freshness, and escalation are checked before the reference transition is admitted. Gate output is `ALLOW`, `REJECT`, or `ESCALATE`; materialization requires fresh independent review or human sign-off.
5. **Config as delta** — schedules, prompts, role/routing policy and governance-policy configuration are represented by deterministic before/after hashes, exact changed fields, DesignEpoch, provenance and source-obligation links. No-op, hidden cross-epoch mutation, or hidden source-obligation rebinding fails closed.
6. **Constitutional tier** — changes to ActionGate rules, authority-envelope rules, or DesignEpoch-binding rules are classified `CONSTITUTIONAL` and require explicit human sign-off; independent agent review alone cannot authorize them.
7. **Level-2 falsifiability** — public `garden-swarm/ATTACK_SURFACE.md` now includes attacks on Garden governance of its own evolution (merged through public PR #41).

## Deterministic evidence

Private kernel and seed CI passed after Steps 1–4, after Steps 5–6, and after final exports. Tests cover typed action closure, fail-closed conditions, epoch invalidation/re-derivation, role authority, delegation narrowing, gate decisions, governed config deltas, and constitutional escalation.

The implementation remains a bounded reference/application profile. Passing these tests does not certify all Garden semantics or prove that every future orchestration path uses the reference gate correctly.

## Throughput rule

The original hold is satisfied: Steps 1–4 now exist and are tested. This removes the *correctness prerequisite* that previously blocked later challenger/ledger/scaling work, but does not require those throughput features to be enabled immediately. They should only be activated when they consume the typed/gated interfaces rather than bypassing them.

## Failure guards

- **Repo ahead of design:** no implementation delta may be admitted without a source obligation/provenance link.
- **Activity without progress:** later ledger/metrics must distinguish receipts/activity from admitted deltas and successor progress.
- **Reflexive authority growth:** no agent may create or enlarge its own authority.
- **Stale design state:** stale/UNKNOWN findings/tests/deltas fail accumulation/materialization.
- **Constitutional self-edit:** gate/envelope/epoch-rule changes require the human approval path.
- **Canonical sovereignty:** no agent action type includes canonical promotion; v15.5 remains immutable and human promotion remains outside the agent pipeline.

## Next integration boundary

Merge this reference implementation only as executable DERIVATION infrastructure. It does **not** ratify a new canonical Garden version. Production/hourly orchestration should then be migrated to emit these typed actions/bindings/envelopes/gate receipts before additional agent throughput is scaled.
