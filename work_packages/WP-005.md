# WP-005 — Public swarm candidate intake and cross-reference

Status: OPEN

## Objective

Admit public `garden-swarm` findings into the private Garden integration process only as provenance-preserved candidates. Verify every claimed gap against the complete Garden v15.5 five-file source before proposing a successor patch.

## Required process

1. Freeze the public swarm run receipt, source hashes, role/model identities, and candidate synthesis.
2. Reject malformed or provenance-incomplete outputs.
3. Search the complete five-file canonical source for every affected anchor/term and evidence request.
4. Classify each candidate as ALREADY_COVERED, DEFECT_CONFIRMED, IMPROVEMENT_CANDIDATE, NEEDS_EVIDENCE, or REJECTED.
5. For confirmed defects/improvements, produce affected invariants/contracts/tests and compare against DO_NOTHING.
6. Run applicable semantic/formal/property/security/integration checks.
7. Preserve dissent/blockers; no majority-vote admission.
8. Only a separately reviewed scoped patch may enter a successor candidate.

## Initial source

Public PR: `ankitdcx/garden-swarm#25` and its bounded heterogeneous swarm receipts.

Public swarm output has no automatic authority over `canonical/current/`.
