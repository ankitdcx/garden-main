# WP-002 — Garden source to OCF obligation extractor

**Priority:** 2  
**Class:** DESIGN  
**Status:** OPEN

## Objective
Read the five Garden text sources and emit machine-readable obligations, source anchors, owners, dependencies, gap classes, and an explicit unresolved frontier.

## Required outputs
- source parser/extractor
- ClosureManifest representation
- GapRecord representation
- stable source anchors/hashes
- deduplication rules
- coverage/frontier report
- tests with known source fixtures

## Acceptance
Extractor never claims full coverage when it cannot parse/classify a material section; omissions are reported as frontier items.
