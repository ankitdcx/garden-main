# WP-001 — Minimal executable GSL semantic kernel

**Priority:** 1  
**Class:** DESIGN  
**Status:** OPEN

## Objective
Implement the smallest executable GSL subset needed to represent CLAIM, CONTEXT, typed values, dependencies, obligations, tests, and receipts while preserving epistemic status.

## Required outputs
- parser or typed AST for the selected minimal subset
- explicit claim-status representation
- context and dependency representation
- unsupported/malformed input behavior
- reference positive/negative corpus
- unit tests

## Acceptance
Tests demonstrate semantic/status preservation for the declared subset; unsupported semantics fail explicitly; candidate does not self-certify.
