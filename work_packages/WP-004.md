# WP-004 — Typed verifier bridge

**Priority:** 4  
**Class:** DESIGN  
**Status:** OPEN

## Objective
Implement a verifier registry/adapter layer that records exactly what each checker establishes and refuses to treat compile success, formal proof, empirical evidence, or security tests as interchangeable.

## Required outputs
- verifier registry
- artifact/version/hash pinning
- typed PASS/FAIL/UNKNOWN receipts
- protected-verifier ownership boundary
- stale receipt invalidation
- test adapters using local deterministic fixtures
- tests

## Acceptance
A checker result is scoped to its verifier class and assumptions; unpinned or candidate-owned protected verifiers cannot produce admission receipts.
