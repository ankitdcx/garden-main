# WP-003 — Minimal GSL-KR claim/evidence/dependency store

**Priority:** 3  
**Class:** DESIGN  
**Status:** OPEN

## Objective
Implement a local persistent store for claims, evidence, epistemic states, dependencies, corrections, counterexamples, and supersession without laundering assertions into truth.

## Required outputs
- SQLite schema
- claim/evidence APIs
- dependency and revalidation traversal
- correction/supersession records
- negative-result storage
- query frontier behavior
- tests

## Acceptance
Storage/retrieval/repetition cannot upgrade epistemic status without an explicit admitted evidence transition.
