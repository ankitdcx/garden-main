# WP-006 — Canonical successor materialization

Status: OPEN / WAITING_FOR_ADMITTED_DELTA

## Objective

Materialize the next complete Garden five-file canonical successor only when a coherent set of design changes has survived full-corpus cross-reference and applicable verification.

## Version rule

- Current immutable predecessor: Garden v15.5 / GSL v45.1.
- First successor target: v15.6.
- Do not create v15.6 for a no-op, cosmetic-only, speculative, or unverified change.
- Do not rewrite published v15.5 files in place.
- Create v15.7 only after a distinct subsequent admitted delta exists after v15.6.

## Required inputs

1. Candidate findings with provenance.
2. Full five-file cross-reference showing the issue is not already covered.
3. DO_NOTHING comparison.
4. Affected contracts, invariants, schemas/tests/registries and semantic anchors.
5. Applicable executable/formal/empirical/security evidence or an explicit pending boundary.
6. Predecessor-retention / no-semantic-loss check.

## Required outputs

- `Garden_User_v15.6_FULL_<date>.txt`
- `Garden_System_v15.6_FULL_<date>.txt`
- `Garden_Technical_v15.6_FULL_<date>.txt`
- `Garden_Annexure_v15.6_FULL_<date>.txt`
- `Garden_Theories_v15.6_FULL_<date>.txt`
- release/change map from v15.5 -> v15.6
- source hashes and reference-closure receipt
- GSL-COMPARE / DO_NOTHING comparison
- explicit certification boundary (`described != proved != implemented != empirically validated != certified`)

## Admission rule

Agent consensus is not sufficient. A successor is materialized only after admitted design deltas are individually dispositioned and their cross-document consequences are propagated. Published predecessor files remain immutable.

## Current state

No v15.6 canonical suite has yet been materialized. Current public/prototype findings are being triaged into implementation defects, already-covered design mechanisms, or candidate successor hardenings. WP-006 activates when at least one coherent semantic design delta passes the admission process.
