## Document consolidation rules

The folder is a **design corpus**, not a runtime or test workspace. Three noncontrolling one-page guides were folded into this README and removed: `TECHNICAL_DELTA_GUIDE.md`, `RELATION_SIGNATURE_GUIDE.md`, and `TREE_CORE_GUIDE.md`. Their unique warnings are retained above; their earlier content remains recoverable from Git history. Do not delete or merge source documents merely because they share vocabulary: technical clauses, unresolved source-retention obligations, typed relation signatures, theory discovery, recursive closure, and Tree Core have different controlling scopes. Further reductions require source-span comparison and no-loss evidence. No scientific finding or canonical promotion follows from cleanup.
