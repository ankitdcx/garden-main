# Garden Implementation Roadmap

## Stage 0 — Trusted seed
Current Garden text, SCEP, hashes, bounded work-package format, protected verifier registry, persistent ledger.

## Stage 1 — WP-001
Minimal executable GSL semantic kernel.

## Stage 2 — WP-002
Automatic Garden source -> OCF ClosureManifest/GapRecord extraction.

## Stage 3 — WP-003
GSL-KR store for claims, evidence, dependencies, corrections, negative results, and frontier.

## Stage 4 — WP-004
Typed verifier bridge (SEMANTIC / FORMAL / SMT / PROPERTY_TEST / FUZZ / EMPIRICAL / SECURITY / INTEGRATION).

## Stage 5
Garden reads Garden and creates its own bounded backlog.

## Stage 6+
Implement higher-priority obligations recursively; use CMUR and SCEP for review/reward; add larger swarms only after the seed loop is reproducible.
